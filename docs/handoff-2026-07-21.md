## Gotchas

- The local backend venv is Python 3.14, but Cloud Run builds on `python:3.11-slim-bookworm`. Kokoro 0.9.4 requires `<3.13`, so local reproduction of the real Kokoro path is not possible; rely on Cloud Build + logs.
- Do not reinstall or re-add `phonemizer` (vanilla) alongside `phonemizer-fork`; they share the `phonemizer` import namespace and will clash.
- The `deploy.sh` env-var delimiter fix (`^||^`) must be preserved for any future `--set-env-vars` changes that contain commas.
